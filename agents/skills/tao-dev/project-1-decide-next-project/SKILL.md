# Project 1: Decide Next Project

Choose the next project from repo truth, not memory.

## Rules

- Read `Roadmap.md`, relevant `Roadmap/*` task docs, and current git state first.
- Inspect current implementation state when roadmap text is ambiguous.
- If `Roadmap.md` does not contain obvious next tasks, review the previous repo at `~/code/tao-lang`, assume most of its functionality will need to be ordered over eventually, and identify previous-repo items that are appropriate next steps for the current repo state. Use the `old-repo-porting` skill for this review.
- Rank candidates by Tao language value, dependency order, implementation risk, and whether Ro has already signaled priority.
- Present the top candidates with a terse rationale and one recommendation.
- Ask Ro to choose or adjust the recommendation before changing roadmap files.
- Do not write research, plan, or implementation docs in this step.

## Output

- Recommended next project and alternatives.
- Roadmap update made, or exact update proposed if Ro has not chosen yet, including any previous-repo items that should be added.
