# Browser Use

- Prefer the coding app's in-app browser when it supports the task, rather than opening a separate browser window on the machine.
- When a standalone browser is needed, use Google Chrome explicitly. Do not rely on the operating system's default browser, which may open Safari.
- Follow an explicit browser or existing-tab request. Use Safari or another browser when there is a specific reason, such as reproducing a browser-specific bug or testing that engine; state the reason briefly.
- Keep routine inspection and testing in the background. Open a visible browser when the Developer asks to see the page or watch the interaction.
- Reuse the relevant task tab where possible. If the preferred browser is unavailable, report that limitation rather than silently changing the machine's default browser.
