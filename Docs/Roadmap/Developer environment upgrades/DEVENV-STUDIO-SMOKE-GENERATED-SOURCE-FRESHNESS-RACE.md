# DEVENV-STUDIO-SMOKE-GENERATED-SOURCE-FRESHNESS-RACE — Studio smoke generated-source freshness race

- **Status:** Candidate
- **Section:** External
- **Area:** Studio browser acceptance and asynchronous file-list snapshots.
- **Impact:** A contended simulated-user smoke can submit a generated-view move with an outdated source version, delaying the lane and requiring an isolated retry.
- **Evidence:** On 2026-10-04, a Studio smoke inside `./agent unsandboxed land` on `feat/syntax2-integration-foundations` reported `Feed view Move did not complete` with `Tao Studio generated source is no longer current: @/studio/View1.tao`. The full-run summary `.artifacts/logs/verify-full/2026-10-04T23-17-51-552Z-98442-59c21c57/summary.json` classified `studio-smoke-simulated-user` as passed after a timeout under machine contention and an isolated retry. The node log was replaced by retry output; a bounded original excerpt is recorded in `.artifacts/syntax2-studio-freshness-observation.md`. Source inspection confirms `StudioApp.ts:838-849` checks exact `(path, sourceVersion)` membership before the move API. The smoke waits for Undo Keep disk equality before Move (`studio-feed-journey.ts:143-155`); shell file events and query-backed rows refresh through different asynchronous paths. The actual mismatched versions were not logged, so snapshot convergence is a plausible cause rather than a proven deterministic defect. No evidence links this failure directly to comma normalization.
- **Workaround:** Preserve the raw failure and use the runner's controlled isolated retry. That retry passed here; do not weaken source freshness or claim the first run passed.
- **Proposed change:** Log supplied version, shell version and query snapshot revision in this smoke's bounded failure evidence. Add a controlled delayed-snapshot reproduction across Undo Keep and Move. If it demonstrates an early test submission, wait for the same observable file version in both paths before submitting; investigate production synchronization only if the reproduction proves a product defect.
- **Dependencies:** Coordinate with Studio file-list/query owners; retain `StudioApp.ts` freshness protection and distinguish a test synchronization defect from ordinary product failures.
- **Acceptance:** A delayed-snapshot regression deterministically captures the mismatch and the corrected test submits only a current version. Quiet and contended isolated smoke runs pass with no relaxed freshness checks; original failed/retry evidence stays separate.
