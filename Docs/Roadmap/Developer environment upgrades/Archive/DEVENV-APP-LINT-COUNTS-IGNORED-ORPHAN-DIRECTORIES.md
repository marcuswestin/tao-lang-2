# DEVENV-APP-LINT-COUNTS-IGNORED-ORPHAN-DIRECTORIES — App lint counts ignored orphan directories

- **Status:** Resolved
- **Section:** External
- **Area:** Repository lint, generated app output, integration
- **Impact:** Integrating a commit that removes an app can leave ignored generated output behind. Repository lint then requires a README entry for an app whose source no longer exists, blocking finalization.
- **Evidence:** On 2026-10-04, integrating `f537139ae` left `Apps/Test Apps/Effect Outcomes/` with only `.tao/` and `Effect Outcomes.tao.ts`, generated by the earlier check. `git ls-files` and an ignore-aware file listing returned no files there. Finalize failed with `Apps/Test Apps/README.md needs a ## Effect Outcomes entry` in `_repo-lint`; the receipt is `.artifacts/logs/verify/2026-10-04T08-22-48-709Z-13205-efe91ae8/repo-lint.log`.
- **Workaround:** After proving a directory contains only owned, inactive, ignored output and no tracked source, remove that output before retrying verification.
- **Proposed change:** Derive the app-directory inventory from active source rather than raw directories, and test integration that removes an app after generation.
- **Dependencies:** None.
- **Resolution:** `feat/project-modules-sidecars` inventories app and starter folders from existing, ignore-aware authored Tao sources instead of raw directories. Removed apps no longer require README contracts because generated contracts, configuration, dependencies, or empty markers remain on disk. The integration also removes tracked markers and configurations left in the five retired app locations.
- **Acceptance:** `./agent test-file packages/testing/verification/verification-tests/repo-lint.test.ts` passed 72 tests on 2026-10-04. The regression covers ignored output, untracked nested source, starter contracts, and deletion while output remains.
- **Mutation proof:** Restoring the original raw-directory inventory made the new regression fail on the ignored and removed folders. Restoring the fix passed all 72 tests again; `.artifacts/logs/dev-test-mutation/2026-10-04T09-26-07-766Z-19680-57f84f8e/summary.json` records the intentional failure.
- **Source:** Landing barrier `.artifacts/logs/check/2026-10-04T09-16-18-772Z-10222-ffe81ac8/repo-lint.log`; focused test `.artifacts/logs/dev-test/2026-10-04T09-23-44-033Z-96214-f0efb299/summary.json`.
