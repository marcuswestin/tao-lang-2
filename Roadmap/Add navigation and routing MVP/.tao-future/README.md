# Navigation Design Examples

These non-executable `.tao` files are implementation inputs for the navigation roadmap. Tao discovery skips this dot-prefixed `.tao-future` directory.

`.tao-future` is a repository convention, not Tao syntax or configuration. Move examples into executable apps or tests as their features are implemented.

`Writer.tao` exercises the complete intended navigation model. `tao-navs.tao` sketches the matching standard-library contracts.
