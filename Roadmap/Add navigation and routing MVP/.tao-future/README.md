# Superseded navigation stdlib sketch

`tao-navs.tao` is the original navigation standard-library sketch. It is superseded by
`Apps/WordFlower/2 - Next/@tao-next/`, which declares navs and datasources in Tao and binds their
semantics through published runtime protocols, and which graduates into
`packages/runtime/tao-stdlib` when its tranche is absorbed.

This directory is the last user of the `.tao-future` convention; the WordFlower tiers keep sketches
out of Tao discovery by file extension instead. Delete this directory once its remaining ideas are
confirmed captured.
