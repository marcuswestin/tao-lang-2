# Tao Skills

Read [tao-project](tao-project/SKILL.md) for the project shape and edit loop. Then open only the
skill that fits the task:

- [tao-create](tao-create/SKILL.md): create an app or add a feature.
- [tao-syntax](tao-syntax/SKILL.md): write Tao declarations and expressions.
- [tao-visibility](tao-visibility/SKILL.md): resolve names across files and packages.
- [tao-layout](tao-layout/SKILL.md): arrange and size views.
- [tao-design](tao-design/SKILL.md): work with colors and design bundles.
- [tao-data](tao-data/SKILL.md): model entities, queries, and fixtures.
- [tao-navigation-actions](tao-navigation-actions/SKILL.md): navigate and handle actions.
- [tao-testing](tao-testing/SKILL.md): write behavior journeys and review scenarios.
- [tao-run-and-ship](tao-run-and-ship/SKILL.md): run and deliver the app.
